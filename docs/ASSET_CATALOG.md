## Original assets

Original code-generated terrain/ocean, curved palm fronds, coastal rocks, road ribbons/curbs/markings, lighthouse, utility details, fishing-boat hull/deck/mast/rigging and synthesized wave audio are authored in this repository. These are not attributed to a third-party library. Building architecture remains stylized; a future realism pass should replace generic assets with more locally specific models.

## Geographic data

OpenStreetMap snapshot (`public/data/osm-source.json`), processed coordinates (`public/data/phu-quy.json` and `src/world/geography.json`): ODbL 1.0, © OpenStreetMap contributors. Fetched 2026-11-25 using `scripts/asset_acquisition/geography.py`. Coastline has 6 closed rings, main island 376 source points, 41 road alignments. Heights are artistic approximations; no elevation dataset is claimed.
